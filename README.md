# AIVA CLINIC — сайт клиники

Многостраничный сайт клиники терапии, физиотерапии и реабилитации AIVA CLINIC (Астана).

**Стек:** Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Lucide Icons.
Анимации сделаны на CSS (без тяжёлых библиотек), все страницы собираются статически.

## Запуск

```bash
npm install
npm run dev      # разработка: http://localhost:3000
npm run build    # сборка
npm run start    # запуск собранного сайта
```

## Перед публикацией

1. Скопируйте `.env.example` в `.env` и заполните:
   - `NEXT_PUBLIC_SITE_URL` — адрес сайта (используется в canonical, sitemap, Open Graph, Schema.org);
   - `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` и/или `BOOKING_WEBHOOK_URL` — куда отправлять заявки с формы.
     Если ничего не задано, после проверки формы пациенту предлагается отправить готовое сообщение
     в WhatsApp клиники — заявка не теряется.
2. В `src/lib/site.ts` укажите юридическое лицо клиники (`legal.entity`, `legal.bin`, `legal.email`) —
   оно подставляется в политику конфиденциальности и согласие на обработку данных.
3. Отдайте тексты `/politika-konfidencialnosti` и `/soglasie-na-obrabotku-dannyh` на проверку юристу.

Сайту нужен Node.js-хостинг (Vercel, собственный сервер с `npm run start` и т. п.): серверная часть
проверяет заявки и оптимизирует изображения.

### Как добавить фотографии

Оригиналы лежат в `_materials/` (в репозиторий не попадают). Положите новый файл в
`_materials/photos`, добавьте его в список в `scripts/prepare-assets.mjs` и выполните
`npm run assets` — скрипт подготовит оптимизированные версии в `src/assets`.
Тем же скриптом из фирменного PDF генерируются векторный логотип, иконки и Open Graph-изображение.

## Структура страниц

- `/` — главная
- `/uslugi` — каталог; `/uslugi/[направление]`; `/uslugi/[направление]/[услуга]`
- `/vrachi`, `/vrachi/[врач]`
- `/o-klinike`, `/akcii`, `/kontakty`
- `/politika-konfidencialnosti`, `/soglasie-na-obrabotku-dannyh`
- `/sitemap.xml`, `/robots.txt`, `/manifest.webmanifest`
- `/api/booking` — приём заявок (проверка данных, защита от спама, доставка)

## Принципы контента

На сайте используются только сведения из материалов клиники. Цены указаны лишь там, где они есть
в документах клиники. Отзывы, регалии врачей, показания и результаты лечения не выдумывались:
если данных нет — блок не выводится или ведёт на независимую площадку (2ГИС).
